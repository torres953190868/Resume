## 工作职责

### 数字化开发方向

1. 参与智能座舱云端 AI 能力的研发与落地，覆盖语音对话、智能推荐和多模态识别等场景。
2. 参与 LLM Harness 评测体系建设，协助构建评测数据集、开发自动化评测脚本并分析效果回归。
3. 参与云端 Agent 平台开发，协助设计和编码多智能体编排、工具调用及记忆管理等模块。
4. 参与云端推理链路优化，协助性能调优、问题排查和线上稳定性保障。
5. 跟踪 LLM、多模态和 Agent 等前沿技术，输出技术调研与方案验证结论。

### 产品规划方向

1. 从业务需求、用户分析、行业趋势和竞品分析等方面定义产品概念方案、交互框架与视觉风格。
2. 负责车联网产品人机交互、视觉与体验设计，覆盖从设计策略到执行的流程。
3. 负责 2D / 3D 动效设计与制作。
4. 参与用户调研、趋势分析、竞品调研与可用性测试，分析并持续优化产品体验。
5. 跟进研发状态和进度，协同解决设计实现问题，完成设计走查、验收并推动落地。

## 任职要求

1. 国内大学统招本科及以上学历的 2026 / 2027 届毕业生；或在两年内取得海外院校本科及以上毕业证、能够于 2027 年入职的留学生。
2. 专业范围包括计算机、软件工程、通信工程、人工智能、电子信息、自动化、数学、统计学及相关专业；产品规划方向还包括工业设计、设计学、美术学等相关专业。
3. 国内毕业生要求 CET-6 425 分及以上；海外留学生满足下列条件之一：托福 80 分及以上、雅思 6.0 及以上、TestDaF 16 分及以上、DSH-2 及以上或 CET-6 425 分及以上。符合特定早期留学、预科、语言课程或联合培养情形者可按要求提供证明材料。
4. 具备熟练的英语或德语听说读写能力，能够进行技术交流。
5. 数字化开发方向需熟悉 Python、Java、Go 中至少一门语言，具备数据结构与算法基础，了解 Transformer、Prompt、RAG 等大模型基础原理；对 LLM、Agent、多模态方向有浓厚兴趣者优先。
6. 产品规划方向优先考虑具备独立作品设计经验者，包括但不限于座舱娱乐系统 HMI（UE / UI）设计；熟悉 AE、动效或 3D 设计者优先。
7. 身体健康、成绩优秀。

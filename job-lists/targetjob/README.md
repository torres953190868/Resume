## 文件命名建议

- JD：`JD-岗位名称.md`、`JD-岗位名称.pdf` 或保留招聘方原始文件名。
- 简历源文件：`简历-岗位名称.typ`。
- 导出简历：`简历-岗位名称.pdf`。
- 投递记录：`投递记录.md`。

定制简历时以根目录经历库为事实来源，并遵循 [Rules.md](../../Rules.md)，不要把待核实信息写成确定事实。

1. [数据闭环平台开发工程师（后端）](JD-数据闭环平台开发工程师-后端.md)：主选，北京 / 上海，本科及以上；2027 届（2026-09-01—2027-08-31 毕业，大陆以毕业证、非大陆以留服证为准），最高学历毕业后无全职工作经验。
   - 岗位要求（已核实）：CS / 软件相关背景；后端开发、数据处理与交互系统。
   - 选岗理由：CARIZON 各方向中与 AI 最相关且与现有基础最匹配的方向——智驾数据闭环平台的后端与数据处理系统，可直接对应 SQL 与数据项目（Text-to-SQL）、自动化评测与数据分析（LLM-as-a-Judge）、异步任务与数据管线（BranchMind）；属第一批方向。

# CARIZON 酷睿程

用于保存 CARIZON 目标岗位的 JD、定制简历和投递记录。

## 投递限制（2026-09-22 核实）

- 官方校招门户不设单岗 JD 页，按方向投递，具体 JD 在移动端投递流程内查看。
- 每人限投 2 个职位；网申 2026-08-24 至 2026-11-30；笔试 9 月上旬起、面试 9 月中旬起、offer 11 月初。
- 按用户指示“有限制则先挑 1 个”：本次先准备 1 份简历；第二志愿槽位保留，是否用满 2 个名额由用户投递前决定，并以投递系统最新规则为准。

## 当前目标岗位

1. 数据闭环平台：主选，北京 / 上海，本科及以上，2027 届（2026-09-01—2027-08-31 毕业，留学生以留服认证为准）。
   - 岗位要求（已核实）：CS / 软件相关背景；后端开发、数据处理与交互系统。
   - 选岗理由：CARIZON 各方向中与 AI 最相关且与现有基础最匹配的方向——智驾数据闭环平台的后端与数据处理系统，可直接对应 SQL 与数据项目（Text-to-SQL）、自动化评测与数据分析（LLM-as-a-Judge）、异步任务与数据管线（BranchMind）；属第一批方向。
   - 与“数据挖掘 / 闭环算法”相比：后者更偏智驾数据挖掘算法，要求 Python/C++、SQL、Linux/shell、sklearn/PyTorch/TF，顶会论文或智驾实习加分；按已核实清单“更适合冲刺，不作为主投”，因此主选数据闭环平台。
   - 主要缺口：Linux、数据管道证据较弱，列为面试准备项，不写成已掌握成果。
2. 第二志愿候选（本次不制作简历）：数据及应用测试（Agent 评测与失败案例分析经历直接对口）、云服务（Agent 后端 / API / 部署经验相通）。若用满 2 个名额，优先在二者中二选一。

该校招项目存在投递数量限制，最终第二志愿应在云服务和数据及应用测试中二选一，并以投递系统的最新规则为准。

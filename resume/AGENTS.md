# 简历编辑约定

- 接到目标岗位后，先阅读 `../rules.md`、`../经历库记录规范.md` 和 `../AGENTS.md`，再打开相关经历、技能和岗位资料的原始记录。
- 只在 `src/chinese.typ` 或 `src/english.typ` 中组织针对岗位的简历内容；`template/` 是共享排版代码，只有需要调整版式时才改动。
- 仓库自带的姓名、学校、联系方式、经历、成绩和头像都是示例。制作真实简历时先替换或删除，不得将示例内容当作用户事实。
- 未提供的个人资料和未经核实的指标留作待确认，不猜测、不编造；每项经历或论文都应能追溯到 `../experiences/`、`../projects/`、`../skills/` 或 `../publications/` 中的记录。
- 修改后编译并检查 PDF 的内容与分页；对外分享前核对事实、链接、保密信息和个人隐私。
- 本项目的 Typst 安装在 `.local/bin/typst`，运行 `make` 时会优先使用它；中文字体放在 `fonts/`。二者的下载文件不纳入 Git。
